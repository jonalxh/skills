## 📌 Overview
`theme-factory` provides a curated suite of 10 cohesive, production-grade visual themes. Each theme includes carefully matched color palettes with hex values and complementary font pairings for headers and body typography.

---

## 🌈 Available Preset Themes

Specifications for all 10 themes reside in the [`themes/`](themes/) directory:

1. **`Modern Minimalist`**: Clean, contemporary grayscale palette for maximum versatility, architectural projects, and tech showcases.
2. **`Tech Innovation`**: Bold, modern tech aesthetic for developer tools and engineering platforms.
3. **`Arctic Frost`**: Cool, crisp winter-inspired theme offering clarity and Nordic freshness.
4. **`Desert Rose`**: Soft and sophisticated dusty tones for understated warmth and elegance.
5. **`Ocean Depths`**: Deep maritime blues inspiring trust, serenity, and professional polish.
6. **`Sunset Boulevard`**: Warm, vibrant sunset colors with high visual impact.
7. **`Forest Canopy`**: Natural, grounded earth and foliage tones rooted in the organic world.
8. **`Golden Hour`**: Rich, warm autumnal palette with sophisticated amber and ochre accents.
9. **`Botanical Garden`**: Fresh, lively botanical greens for organic, healthy, and eco-friendly products.
10. **`Midnight Galaxy`**: Dramatic, deep cosmic dark tones for immersive interfaces with high contrast.

---

## 🛠️ On-the-Fly Custom Theme Generation
If none of the pre-built themes fit a specific brief, the skill can generate a custom theme following the same rigorous standards:
- Base, surface, border, and accent colors.
- Header and body font pairings.
- Conceptual rationale aligned with the user's project.
